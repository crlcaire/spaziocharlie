SPAZIOCHARLIE · Carlo Caire – Creative Space
============================================

Contenuto della cartella
- index.html ...... la pagina del sito
- img/ ............ cover, collage, ritratto e logo
- fonts/ .......... font Mont (Regular, SemiBold, Heavy)
- .nojekyll ....... file tecnico per GitHub Pages (non cancellarlo)

PUBBLICARE SU GITHUB PAGES
Questo sito va in un repository NUOVO, separato da quello del portfolio
principale, così i due siti non si sovrascrivono.

1. Su github.com, in alto a destra: "+" > "New repository".
   - Nome: spaziocharlie
   - Visibilità: Public. Clicca "Create repository".
2. Nella pagina del repository clicca "uploading an existing file".
   Trascina TUTTO il contenuto di questa cartella (index.html, img, fonts, .nojekyll)
   e clicca "Commit changes".
   Nota: .nojekyll è un file nascosto; su Mac premi Cmd+Shift+. nel Finder per vederlo.
   Le cartelle img e fonts vanno trascinate intere, non aperte.
3. Vai su Settings > Pages. In "Build and deployment" scegli
   Source: "Deploy from a branch", Branch: "main" / "(root)", poi Save.
4. Dopo 1-2 minuti il sito è online qui:
   https://NOMEUTENTE.github.io/spaziocharlie/
   (NOMEUTENTE = il tuo nome utente GitHub)
   Il link esatto compare in alto nella pagina Settings > Pages.

VERSIONE INGLESE
Aggiungi #en in fondo al link per aprire il sito direttamente in inglese:
   https://NOMEUTENTE.github.io/spaziocharlie/#en

SE HAI GIÀ CARICATO LA VERSIONE "cover-collage"
Puoi rinominare quel repository in Settings > General > Repository name
(scrivi spaziocharlie) e poi caricare questi file sopra i vecchi.
Il vecchio file img/logo_cc_light.png non serve più: puoi cancellarlo.

SE HAI UN DOMINIO TUO (es. carlocaire.it)
Se il portfolio principale è già collegato al dominio, questo sito
sarà automaticamente anche su https://carlocaire.it/spaziocharlie/

AGGIORNARE IL SITO
Nel repository: "Add file" > "Upload files" e carica i file modificati:
quelli con lo stesso nome vengono sostituiti.

NOTA SUL FONT
Mont è un font commerciale (Fontfabric). Verifica che la tua licenza
copra l'uso web prima di pubblicare il sito.
